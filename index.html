Adding Product

  • Must start with a capital letter followed by 2–8 lowercase letters.
  • Must contain a space followed by 2–8 characters.
  • Enter a valid positive price (e.g., 50 or 99.99).
  • Cannot start with zero or be negative.
  • Must be one of: TV, Mobile, Screens, or Electronic.
  • Description cannot be empty and must be under 1000 characters.
  • Must select a file with an extension: jpg, jpeg, png, webp, or svg.
  • File name should not exceed 10 characters before the extension.
